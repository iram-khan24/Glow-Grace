# 🌸 Glow & Grace - Beauty Salon Website

Glow & Grace is a modern and elegant beauty salon website created using HTML, CSS and JavaScript.

The website provides information about salon services, team members, gallery, frequently asked questions and an appointment form.

## ✨ Features

- 🏠 Home section -----------
- 💇 Services section
- 👩 About Us section
- 👩‍🎨 Team section
- 🖼️ Gallery section
- ❓ FAQ section
- 📅 Appointment form
- 🌙 Light/Dark theme
- 📱 Responsive design
- 📞 Contact information
- 🕐 Opening hours

## 🖼️ Gallery

The gallery is divided into four categories:

- Salon
- Hairstyle
- Makeup
- Beauty

Each category has its own separate page.

## 📅 Appointment Form

Users can submit their preferred appointment details, including:

- Name
- Phone Number
- Service
- Occasion
- Preferred Date
- Preferred Time
- Message

> **Note:** The appointment form is only for demonstration purposes. It does not create a real booking.
